# liberary-app
🟦 About the App

Library is a modern library management application designed in Figma to help users easily search, borrow, and manage books. The clean interface, simple navigation, and organized layout create an easy and enjoyable library experience.

🎨 Color Palette

🟦 Primary – #2563EB
📘 Represents Knowledge, Trust & Learning

🟩 Secondary – #22C55E
🌱 Represents Growth, Progress & Success

🟨 Accent – #FACC15
✨ Highlights Important Actions & Notifications

⬜ Neutral – #F8FAFC
🤍 Creates a Clean & Comfortable Interface

📖 Design Inspiration

📚 Book Collection – Explore different books and categories.

🔍 Search Books – Quickly find books using the search option.

👤 User Profile – Manage personal information and borrowed books.

📖 Book Details – View book title, author, category and availability.

🔄 Borrow & Return – Easily borrow and return library books.

🔔 Notifications – Get reminders about due dates and library updates.

📱 Modern UI Design – Simple, clean, and easy to navigate.
